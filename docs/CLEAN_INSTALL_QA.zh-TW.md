# Quill 乾淨環境驗收

目標：用「從未執行過 Quill」的 macOS 使用者帳號，驗證朋友實際遇到的完整流程。

## 測試矩陣

| 系統 | Apple Silicon | Intel | 結果 |
|---|---:|---:|---|
| macOS 13 | 必測 | 可取得設備時測 | |
| macOS 14 | 必測 | 可取得設備時測 | |
| macOS 15 | 必測 | 可取得設備時測 | |
| 最新 macOS | 必測 | 非必要 | |

沒有實體 Intel Mac 時，至少保留 CI 的 Universal binary 驗證，並請一位 Intel
使用者完成一次安裝。

## 建立乾淨環境

1. 系統設定 → 使用者與群組 → 新增「標準」測試帳號。
2. 登入測試帳號，不複製既有 Quill 偏好設定或 Keychain。
3. 從正式官網下載 `Quill.zip`，不要使用 DerivedData 內的 App。

## 安裝與首次啟動

- [ ] ZIP 能正常解壓縮，Quill.app 可移至 Applications。
- [ ] Beta：依官網說明使用「仍要打開」；正式版：直接雙擊可開啟。
- [ ] 首次啟動自動顯示設定引導。
- [ ] 輔助使用權限能正確開啟系統設定。
- [ ] 螢幕錄製權限要求重新啟動後，Quill 自動回到該引導步驟。
- [ ] 完成後選單列出現 Quill logo，不需要回到 Dock 尋找 App。

## 核心流程

- [ ] `Control + Option + Q` 可框選畫面並取得 AI 回覆。
- [ ] `Control + Option + A` 可處理選取文字。
- [ ] Preferences 顯示截圖快捷鍵在上、選字快捷鍵在下。
- [ ] 每日第 11 次顯示額度訊息與「查看升級方案」。
- [ ] 「查看升級方案」開啟官網，點「我想升級 Pro」會進入安全結帳入口或誠實的尚未開放頁。
- [ ] 無網路、AI 服務錯誤與錯誤 API Key 都有可理解的錯誤，不會當機。

## 更新與移除

- [ ] 選單列「檢查更新」能讀取 appcast。
- [ ] 有新版本時，舊版可完成下載、驗證、重啟與升級。
- [ ] 移除 App 後不會留下背景程序。

## 證據

每個系統至少保存：

- 安裝成功截圖
- 權限重啟後自動返回引導的截圖
- 截圖快捷鍵成功結果
- 選字快捷鍵成功結果
- 更新成功畫面（正式版）
