Privacy

只處理完成功能所需的資料。

Quill 不建立使用者帳號，也不把你的截圖、選取文字、Prompt 或 AI 回覆保存成資料庫。

生效日期：2026 年 7 月 28 日

1. Quill 處理哪些資料

  • 你要求 AI 處理的內容：截圖、選取文字與指令會經 Quill Cloud 傳送至 AI 服務，只用來產生當次回覆，不寫入 Quill 的內容資料庫。
  • 匿名使用指標：活躍使用、達到每日限額、查看升級與開始結帳等事件。安裝識別碼只在伺服器以 HMAC 匿名化後去重。
  • 安全與濫用防護：網路位址可能短暫用於速率限制，或經 HMAC 後用於結帳意願去重；不以原始形式加入分析資料。
  • 自行設定的 API Key：只保存在 macOS Keychain，Quill Cloud 不會收到它。
  • 付款與訂閱資料：升級 Pro 時，Portaly 會處理付款方式、電子郵件、交易與訂閱狀態。Quill 只保存啟用額度所需的訂閱識別與狀態，不保存完整卡號。

2. 使用目的

提供 AI 回覆、執行每日免費額度、維持服務安全、了解多少匿名使用者遇到限額或希望升級，以及處理未來的付款與售後服務。

3. 保存期限

匿名原始事件與額度紀錄最多保存 90 天；彙總後的統計可能保留更久，但不包含可直接識別個人的內容。AI 請求內容不由 Quill 保存。

4. 服務供應商

Quill 使用 Railway 提供雲端執行環境、OpenAI 產生 AI 回覆、GitHub Pages 提供官網，並由 Portaly 提供付款、訂閱管理與交易通知。付款資料依 Portaly 的政策處理，Quill 不保存完整信用卡資料。

5. 你的選擇

你可以停用 Quill Cloud 並改用自己的 API Key、停止使用 App，或移除 App。因 Quill 不要求帳號且指標已匿名化，我們通常無法把匿名事件重新連結到特定個人。

6. 問題與更新

一般問題可透過 GitHub Issues 聯絡；請勿在公開 Issue 貼出敏感內容。涉及安全或私人資料時，請使用 GitHub repository 的私人安全回報功能。政策有重大變更時，會更新本頁日期與內容。

這份政策描述目前實際運作方式；Quill 不出售個人資料，也不使用你的內容訓練模型。
